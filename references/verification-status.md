# 逐项证据等级

这份表回答一个问题：**报告里的每一条结论，凭什么说它成立？**

同一张总表里 28 行的证据强度并不一样。有的是本机当场跑出来的读数，有的是浏览器回传，有的只能读配置推断，还有的只有合成夹具在守。把它们混在一起说「体检通过」，就是拿测试数量冒充能力覆盖。

> 日期取 `SKILL.md` 和 `references/` 里记录过的实测；没记具体日期的只写月份，不编日期。换机器、换 macOS 版本、换代理客户端之后，这些等级和日期都可能变旧，**变旧就按「未验证」看**。

## 五个等级

| 等级 | 含义 | 能证明什么 |
| --- | --- | --- |
| **实测·脚本** | 本机真实运行，脚本自己读到或打到 | 这一项在这台机器上确实被检查过 |
| **用户回传** | 本机回环复核页把结果投回脚本（`openedBy=script` 才算） | 这个浏览器资料确实打开了复核页并回了结果 |
| **配置读取** | 只读配置文件 / 日志 / 系统状态推断 | 配置现在是什么样，不等于运行时行为 |
| **仅合成** | 只有夹具单测覆盖，未做真机复验 | 代码路径与判据逻辑，不等于真实环境 |
| **人工** | 只能用户自己核对 | 清单给路径与判据，结论要人给 |

## 明确不算证据的东西

- **单测数量**。800+ 个用例证明判据逻辑被守住，不证明这台机器真实环境如何。
- **CI 绿**。CI 跑在 macOS runner 上，用合成夹具；它验证代码，不验证你的系统设置。
- **一次成功**。网络会抖、代理会换 IP、浏览器会重启；一次通过只代表那一次。
- **报告页漂亮**。页面只重排同源读数，不是新证据。
- **人工检测站的结果**。它们只作参考，不进判定（见 `references/manual-checklist.md`）。

## 会变旧的东西

| 会变旧的 | 怎么发现 |
| --- | --- |
| 浏览器复核缓存 | 24 小时过期，`profileScope` 对不上也作废 |
| 出口历史 | 换订阅、服务商换 IP 都会变；变了报待处理而不是 ✗ |
| 住宅 IP 判定缓存 | 一周过期，过期后重新多源交叉 |
| mihomo / sing-box / Clash Verge 版本行为 | 版本升级后重跑 `--check`，别照旧结论用 |
| 第三方检测站与扩展 | 商店页、扩展 ID 都可能变，`--install-webrtc-limiter` 每次重新核对签名公钥 |

规则只有一条：**没测到就写没测到，日期旧了就写未知。** 报告和这份表都不允许把「以前测过」说成「现在成立」。
