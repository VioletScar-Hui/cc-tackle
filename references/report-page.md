# 报告页：静态 HTML 与可点修复

这个 skill 每跑完一次都会落一份自包含的 HTML 报告；另有本地服务模式，让页面上的按钮直接执行修复。

## 静态报告

三条入口都会生成，落在 `~/ClaudeGuardBackups/report-<时间戳>.html`：

| 入口 | 行为 |
|---|---|
| `python3 scripts/selfcheck.py` | 生成并自动打开 |
| `python3 scripts/account_guard.py --audit` | 只落盘、打印路径 |
| `python3 scripts/account_guard.py`（完整加固） | 生成并打开，另存一份同时间戳 JSON 与之配对 |

页面自上而下是：总分（**加分制**：27 个基础项合计 100 分、每项 100/27 分，通过拿满、待处理拿一半、未通过 0 分，**「没测到」分子分母都不进**；「登录方式」是额外加分项，通过再加 5 分，所以满分 105）与计数、关键实测那一排；分组通过率；需要你处理的事项；逐项结果（每项可展开「看依据」，摊开来源字段的原始 JSON）；必须人工做的条目。

两条硬约束写在 `scripts/report_html.py` 里：**整页不引用任何外部资源**（没有 CDN、没有 web font、没有 JS），**页面上的数字全部来自报告本身**（判定复用 `build_summary`，不另写一套，免得页面说通过、终端说不通过）。

手动重渲染某一份：`python3 scripts/report_html.py [报告.json] --out ~/Desktop --open`。设 `CLAUDE_GUARD_NO_OPEN=1` 可以不自动打开浏览器。

## 可点修复：本地服务模式

```bash
python3 scripts/report_serve.py
```

体检完起一个只绑 `127.0.0.1` 的服务并打开页面。能自动修的项右边多一个按钮，点一下执行、页面刷新、顶部写明这次做了什么；顶部另有「修复全部可自动修的项」和「重新体检」，页脚「结束本地服务」，空闲 30 分钟自己退出（`--timeout` 可调）。

安全边界不可放宽：只监听回环、端口随机；URL 路径带 48 位随机令牌并用 `hmac.compare_digest` 比对，不带或不对一律 404；POST 还需自定义头 `X-Guard-Token`（跨站表单发不出自定义头），缺了 403；动作只认白名单，行名对不上 400；并校验 Origin。

按钮只出现在这个 skill 本来就敢自己做的事上：系统代理残留、shell/npm/git 代理、settings.json 端点与凭据、Clash DNS、浏览器 Intl、系统级可清理量、settings 失效权限、项目级垃圾与失效工作树注册。**需要人拿主意的（遥测开关、IPv6、定位服务）和必须人工的（手机时区、支付、浏览器隔离）不出按钮** —— 出了就是骗人点。

点按钮的顺序和终端流程一致：**先备份、再改**。备份里存的是改动之前的原文；备份失败就一个字符都不改，而不会出现「改完了才发现没备份」。目标已经有别人改好了（比如系统代理残留被定时脚本先清掉）时按「无需改动」报，不当失败——只有发现目标被改成了更危险的状态（残留变成了启用的代理）才拒绝执行。

删掉的旧版本与缓存没法像配置文件那样回滚，所以每次清理都会在 `~/ClaudeGuardBackups/cleanup-<时间戳>.json` 留一份账本，写明删了哪些路径、各多大。这条路径 2026-10-13 之前不写账本，是后来补的；补之前的删除可以按当时那份 `audit-*.json` 里的 `A25_claude_storage` 回溯补记。

## 为什么静态页不出按钮

`file://` 页面执行不了本机命令。摆一个点不动的按钮只会让人以为点了有用，所以静态那份保持零按钮、零 JS —— 这一点有用例守着。
